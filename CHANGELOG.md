# Casino App - Change Log

## Дата: 18 декабря 2025

### ✅ Реализовано: Обновление баланса в реальном времени

#### Изменения в RouletteViewController:

1. **Добавлен NotificationCenter Observer**
   - Подписка на `UserManager.didUpdateNotification`
   - Автоматическое обновление баланса при любых изменениях
   - Правильная очистка в `deinit`

2. **Добавлен метод `viewWillAppear`**
   - Обновление баланса каждый раз при появлении экрана
   - Синхронизация с общим балансом приложения

3. **Улучшен метод `handleUserManagerUpdate`**
   - Проверка изменения баланса через `userInfo`
   - **Анимация перехода текста** (cross dissolve, 0.3 сек)
   - **Эффект пульсации** (scale 1.1x) для привлечения внимания
   - Плавный возврат к нормальному размеру

4. **Интеграция с UserManager**
   - `spinButtonTapped()` - вычитает ставку через `addCredits()`
   - `checkWin()` - добавляет выигрыш через `recordGameResult()`
   - Баланс обновляется автоматически через NotificationCenter
   - Нет необходимости вручную вызывать `updateBalance()`

#### Преимущества:

✅ **Реальное время** - баланс обновляется мгновенно при любых изменениях
✅ **Анимация** - плавный переход и эффект пульсации привлекают внимание
✅ **Синхронизация** - баланс синхронизирован между всеми экранами
✅ **Автоматизация** - не нужно вручную обновлять UI

#### Поведение:

- При размещении ставки → баланс уменьшается с анимацией
- При выигрыше → баланс увеличивается с анимацией пульсации
- При переходе между экранами → баланс всегда актуальный
- При изменении баланса на других экранах → автоматически обновляется в рулетке

#### Добавленные функции:

1. **Кнопка выхода** - красная неоновая кнопка "✕" в правом верхнем углу
2. **Общий баланс** - интеграция с UserManager для всего приложения
3. **История транзакций** - все ставки и выигрыши сохраняются
4. **Статистика игр** - учитываются игры и победы

## Технические детали:

### Используемые API:
- `NotificationCenter.default.addObserver()`
- `UserManager.didUpdateNotification`
- `UIView.transition(with:duration:options:animations:completion:)`
- `UIView.animate(withDuration:animations:completion:)`

### Анимации:
1. Cross dissolve (0.3 сек) - плавная замена текста
2. Scale pulse (0.15 сек × 2) - эффект пульсации 1.0 → 1.1 → 1.0

### Производительность:
- Минимальная нагрузка на CPU
- Анимации выполняются на главном потоке
- Нет утечек памяти (правильная очистка в deinit)
